# 14 添加安全网页抓取工具

## Commit 信息

- Commit：[`b58df1e`](https://github.com/qlypupil/mini-agent/commit/b58df1e)
- 类型：`feat`
- 状态：历史实现

## 问题与目标

搜索 Tool 适合发现网页，但模型有时需要读取用户提供的具体 URL。直接 `fetch()` 任意地址会引入 SSRF、重定向绕过、二进制下载和超大响应风险。

本提交增加 `web_fetch`，只允许抓取公网 HTTP/HTTPS 文本资源。

## URL 安全检查

```text
解析 URL
  -> 只允许 http: 和 https:
  -> 拒绝 localhost
  -> DNS 解析全部地址
  -> 拒绝任意私网、回环或链路本地地址
  -> 发起 manual redirect 请求
  -> 每次重定向重新执行同一套检查
```

IPv4 检查覆盖常见私网、回环、链路本地和运营商级 NAT 地址；IPv6 检查覆盖未指定地址、回环、ULA 和链路本地范围。

每次重定向都重新验证目标，防止初始公网 URL 跳转到内网服务。

## 响应限制

- 请求总超时 10 秒。
- 最多跟随 3 次重定向。
- 网络响应最大读取 1 MB。
- 返回给 Agent 的正文最多 8 KB。
- 只把文本、JSON、XML 和 JavaScript MIME 类型作为文本处理。
- 非文本资源只返回类型说明，不下载完整二进制内容。

流式读取响应体时按字节累计，在达到限制后取消 reader，避免先把整个响应加载到内存再截断。

## Tool 输入

模型只提供一个经过 Zod URL 校验的 `url`。运行时仍会重新解析协议、域名和 DNS 地址，因为 Schema 只能证明字符串像 URL，不能证明目标网络位置安全。

## 验证

测试覆盖：

- 正常公网文本响应。
- 私网和 localhost 拒绝。
- 重定向目标重新校验。
- 超时、HTTP 错误和重定向上限。
- 非文本类型。
- 1 MB 响应限制与 8 KB Agent 内容截断。

真实 Agent 验证成功抓取并概述指定网站。

## 当时的边界

- DNS 校验与真正建立连接之间仍存在理论上的 DNS rebinding 时间窗口。
- 不解析 HTML DOM，也不执行 JavaScript。
- 不支持需要登录、Cookie 或浏览器渲染的网页。
- 错误当时以字符串结果返回，后续才改为统一异常协议。
